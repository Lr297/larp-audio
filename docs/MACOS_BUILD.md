# macOS build

Prerequisites: macOS arm64, base Python 3.12, Xcode command-line tools, network
access to the pinned packaging wheels, and checked pinned resources. The build
does not consume the repository `.venv`.

```bash
python3 scripts/build_macos_app.py
python3 scripts/verify_packaged_app.py "dist/LARP Audio.app"
ditto -c -k --sequesterRsrc --keepParent "dist/LARP Audio.app" "dist/LARP-Audio-1.0.0-rc.9-macOS-arm64.zip"
python3 scripts/scan_release_privacy.py "dist/LARP-Audio-1.0.0-rc.9-macOS-arm64.zip"
python3 scripts/build_macos_dmg.py
```

The app builder creates an ephemeral environment, installs exact pins from
`packaging/requirements-macos-arm64.txt`, builds and installs the project wheel,
runs PyInstaller against that installed package, privacy-scans the app, and
applies ad-hoc signing. Editable installs and local checkout metadata are release
failures. The DMG uses `hdiutil`, contains the app plus an Applications symlink,
and is verified, mounted read-only, scanned and detached. No Developer ID certificate
or notarization is used. Reproducibility is bounded by lockfile, pinned inputs
and the SDK; Apple toolchain metadata can still differ across hosts.

The RC icon source is `resources/icons/larp_audio_master.png`. The build uses
`resources/icons/larp_audio.icns`, generated by `scripts/build_app_icon.py` from
the master and all ten native iconset representations. The outer canvas remains
transparent; rounding is part of the asset rather than a runtime style effect.
